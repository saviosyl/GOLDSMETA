# GoldMeta Web PWA

Primary browser client for GoldMeta. Installable via Safari → Share → Add to Home Screen.

See [docs/WEB_PWA_SETUP.md](../docs/WEB_PWA_SETUP.md) for configuration, Hosting, and iPhone steps.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Decisions always come from the shared backend — this app does not run the trading engine.
